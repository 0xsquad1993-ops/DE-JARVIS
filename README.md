# DE-JARVIS

AI-powered Data Engineering automation platform built with Python, PySpark, Streamlit, and Groq AI.

## Overview

DE-JARVIS is designed to help automate data engineering workflows, from source data ingestion and schema discovery to data quality checks, transformations, and Gold-layer outputs.

## Key Features

- AI-assisted command and workflow planning
- CSV source data ingestion
- Dynamic schema discovery and profiling
- Data quality checks and validation
- PySpark-based data transformation
- Bronze, Silver, and Gold layer workflow
- Pipeline orchestration, retries, and execution reports
- Streamlit dashboard for pipeline monitoring
